## 一、密码学与认证安全

### 1. Argon2id 密码哈希
- **源文件**：`ygh-auth-service/.../domain/Argon2PasswordHasher.java`
- BouncyCastle `Argon2Parameters.ARGON2_id`，规范版本 1.3（`0x13`）
- 标准 PHC 编码格式：`$argon2id$v=19$m=...,t=...,p=...$salt$hash`
- 参数上限：内存 ≤32MB，迭代 ≤4，并行度 ≤2
- `owaspMinimum()` 工厂：salt=16B, hash=32B, parallelism=1, memory=19KiB, iterations=2

### 2. 恒定时间密码比较
- **源文件**：`Argon2PasswordHasher.java`
- `MessageDigest.isEqual(actual, parsed.hash())` - JDK 原生恒定时间比较，防时序攻击

### 3. 哈希并发容量保护（防 DoS）
- **源文件**：`Argon2PasswordHasher.java`
- `Semaphore(maximumConcurrentOperations, true)` 公平信号量
- `tryAcquire(5s)` 超时抛 `PasswordHashCapacityException`
- 防止攻击者并发发起大量登录请求耗尽 CPU/内存

### 4. 密码内存安全擦除
- **源文件**：`Argon2PasswordHasher.java`
- salt / hash / encodedPassword 全部 `Arrays.fill((byte)0)`
- `ParsedEncoding.clear()` 擦除内部 salt 和 hash
- `encodingUtf8()` 中 ByteBuffer.array 也擦除

### 5. 哈希参数升级检测
- **源文件**：`Argon2PasswordHasher.java`
- `needsUpgrade()` 比对当前参数与存储参数，判断是否需要重新哈希

### 6. 泄露密码库检查
- **源文件**：`ygh-auth-service/.../infrastructure/ClasspathCompromisedPasswordChecker.java`
- 加载 `/security/common-passwords-sha256.bin`（SecLists 2026.1 xato top 100000，96518 条）
- 密码转小写 -> UTF-8 -> SHA-256 -> **二分查找**已排序哈希数组
- 数据集完整性校验：条数 × 32B = 总长度 + SHA-256 比对
- 所有中间变量 `Arrays.fill((byte)0)` 擦除

### 7. 密码强度策略
- **源文件**：`ygh-auth-service/.../domain/PasswordPolicy.java`
- 最小 15 位，最大 128 位（`Character.codePointCount` 精确计算 Unicode 长度）
- 禁止控制字符（`Character.isISOControl`）
- 调用 `CompromisedPasswordChecker.isCompromised` 检查泄露库

### 8. 凭证规范化
- **源文件**：`ygh-auth-service/.../domain/PrincipalNormalizer.java`
- `strip().toLowerCase(Locale.ROOT)` 去空格 + 统一小写
- 长度 ≤190 code points，禁止控制字符

### 9. 审计脱敏哈希（HMAC-SHA256 + Pepper）
- **源文件**：`ygh-auth-service/.../domain/SensitiveValueHasher.java`
- Pepper ≥32B，HMAC-SHA256 生成确定性审计标识符
- **域分隔**：IP 前加 `0x01`，验证码前加 `0x02`，防跨域碰撞
- `toString()` -> `pepper=[REJECTED]`

### 10. JWT 令牌签发（Nimbus + RSA PS256）
- **源文件**：`ygh-auth-service/.../infrastructure/NimbusAccessTokenIssuer.java`
- `JWSAlgorithm.PS256` 签名
- Claims：iss / aud / sub / jti / iat / nbf / exp + 自定义 account_id / roles / permissions
- 角色和权限 `sorted().toList()` 保证有序
- 生命周期强制 5-20 分钟

### 11. RSA 密钥环管理
- **源文件**：`ygh-auth-service/.../infrastructure/RsaSigningKeyRing.java`
- PEM 手动解析（不依赖第三方 PEM 解析器）
- **不跟随符号链接**（`LinkOption.NOFOLLOW_LINKS`）
- `SecureDirectoryStream` 原子句柄打开文件（防 TOCTOU 竞争）
- 文件大小 ≤32KB（防内存耗尽）
- 密钥强度 ≥2048 位
- `verifyKeyPair`：32B 随机挑战 -> SHA256withRSA 签名 -> 公钥验证
- Key ID 正则校验 `[A-Za-z0-9][A-Za-z0-9._-]{0,63}`
- 所有中间字节数组 `Arrays.fill((byte)0)` 擦除

### 12. POSIX 文件权限检查
- **源文件**：`RsaSigningKeyRing.readWithoutFollowingLinks()`
- `PosixFileAttributeView` + `NOFOLLOW_LINKS` 校验密钥目录权限

### 13. Refresh Token 轮转与重放检测
- **源文件**：`ygh-auth-service/.../domain/RefreshRotationStatus.java` + `RefreshTokenRepository.java`
- 三态：`ROTATED`（成功）/ `INVALID`（无效）/ `REPLAY_DETECTED`（重放检测）
- `rotate()` 令牌轮转，`revokeFamilyByTokenHash()` 撤销整个令牌族
- `JdbcRefreshTokenRepository` 中 `COALESCE` 保留最严重撤销原因

### 14. 账号锁定策略
- **源文件**：`ygh-auth-service/.../domain/AccountLockPolicy.java`
- 失败次数累加达 `maximumFailures` 后锁定 `lockDuration`
- 锁定过期恢复时**重置计数**（`priorFailures = 0`）
- 成功登录重置为 `AccountAccessState.active()`

### 15. 双维度登录限流
- **源文件**：`ygh-auth-service/.../domain/LoginRateLimitPolicy.java` + `LoginRateLimiter.java`
- 账号维度 + IP 维度双限流
- `LoginRateLimitDimension`：NONE / PRINCIPAL / IP / BOTH
- `LoginRateLimitDecision` 返回 `retryAfter` 建议重试时长

### 16. 验证码挑战存储
- **源文件**：`ygh-auth-service/.../domain/CaptchaChallengeStore.java`
- `save(challengeId, answerHash, ttl)` 保存
- `consume(challengeId, answerHash)` 一次性消费，验证后删除防重放

### 17. 令牌主体安全校验
- **源文件**：`ygh-auth-service/.../domain/TokenPrincipal.java`
- 角色正则 `[A-Z][A-Z0-9_: -]{0,127}`，权限正则 `[A-Za-z][A-Za-z0-9:_-]{0,127}`
- 数量 ≤128，编码总长 ≤4096

## 二、Redis 分布式锁与会话管理

### 18. Owner-Token 分布式锁
- **源文件**：`ygh-common-redis/.../RedisDistributedLock.java`
- `SET key owner NX lease` 原子加锁
- `SecureLockOwnerTokenGenerator`：24B（192 位）`SecureRandom` 随机 token，Base64url 无填充
- 释放/续约用 **Lua 脚本**原子校验 owner 后操作
- 租约限制 1s-5min
- Key 必须符合 `ygh:env:service:business:id` 规范格式

### 19. Redis Key 规范化
- **源文件**：`ygh-common-redis/.../RedisKeyBuilder.java`
- 五段格式 `ygh:environment:service:business:identifier`
- 每段独立正则校验，最大 235 字符
- `isCanonical()` 验证 key 是否符合系统规范

### 20. Redis Key 脱敏标识
- **源文件**：`ygh-common-redis/.../RedisKeyIdentifier.java`
- `sha256(value)` 简单摘要
- `hmacSha256(value, pepper)` 带 Pepper HMAC，Pepper ≥32B
- 邮箱等敏感值不直接出现在 Redis key 中

### 21. Session 状态管理
- **源文件**：`ygh-common-redis/.../RedisSessionStateStore.java`
- 注册：`SET session NX ttl`
- 撤销：Lua 脚本原子 `DEL session` + `SET revoked 1 PX ttl`（黑名单，TTL 与原 session 一致）
- 禁用/启用账号：`SET account-state DISABLED/ACTIVE`
- **Hash Tag** `{accountId}` 确保同一用户相关 key 落在同一 Redis slot
- TTL 限制 1ms-31 天

### 22. 响应式 Session 校验
- **源文件**：`ygh-common-redis/.../ReactiveRedisSessionValidator.java`
- `ReactiveStringRedisTemplate` + Lua 脚本一次校验三个 key
- session 存在 + 黑名单不存在 + account-state == ACTIVE
- 返回 `Mono<Boolean>` 非阻塞

### 23. TTL 抖动策略（防缓存雪崩）
- **源文件**：`ygh-common-redis/.../TtlJitterPolicy.java`
- 默认 10% 对称抖动 `[-window, +window]`
- `cacheTtl()` 可刷新缓存条目（TTL 可长可短）
- `minimumRetentionTtl()` 安全/幂等保留期（只正向加，不低于基准）

## 三、消息可靠性

### 24. 本地消息表（Outbox 模式）
- **源文件**：`ygh-common-mq/.../JdbcOutboxDispatcher.java`
- 五张 outbox 表白名单：order / wallet / training / product / knowledge
- 僵死恢复：PROCESSING >2min -> RETRY
- 乐观锁争抢：`UPDATE SET status='PROCESSING' WHERE id=? AND status IN ('PENDING','RETRY')`
- 指数退避：`LEAST(2, retry_count) SECOND`，超过 15 次 -> FAILED

### 25. 幂等消费状态机
- **源文件**：`ygh-common-mq/.../IdempotentMessageConsumer.java`
- 三态认领：CLAIMED（成功认领）/ DUPLICATE（已消费）/ IN_PROGRESS（别人正在处理）
- 租约机制 + 随机 owner token（`SecureMessageClaimOwnerGenerator` 24B）
- **业务与状态同事务**：`executeAndMarkSucceeded` 在同一数据库事务中执行
- 租约过期可被其他节点**强制抢占**
- 超过 `maxAttempts` 或 `NonRetryableMessageException` -> 死信

### 26. JDBC 消费存储
- **源文件**：`ygh-common-mq/.../JdbcMessageConsumptionStore.java`
- `SELECT ... FOR UPDATE` 行锁
- `DuplicateKeyException` 捕获 -> 查询现有状态判断 DUPLICATE / IN_PROGRESS
- `BusinessOperationFailure` 禁用堆栈填充（`false, false`）提升性能
- 竞态处理：主键冲突后查询前行被删除 -> IN_PROGRESS

### 27. 消息信封安全校验
- **源文件**：`ygh-common-mq/.../MqEnvelopePolicy.java`
- eventId / eventType / traceId / producer / businessKey 全部正则校验
- 校验失败抛 `"is not safe for MQ transport"`

### 28. RocketMQ 发布器
- **源文件**：`ygh-common-mq/.../RocketMQDomainEventPublisher.java`
- 同步发送 + `SendStatus.SEND_OK` 确认
- 失败重试 2 次，超时 3s
- 消息属性注入 eventId / aggregateId / schemaVersion

### 29. 死信记录
- **源文件**：`ygh-common-mq/.../DeadLetterRecord.java`
- 不含异常堆栈/原始负载，只有 `failureCode`（`[A-Z][A-Z0-9_]{2,63}`）
- 全字段正则校验

### 30. 消息头时间格式化
- **源文件**：`ygh-common-mq/.../MqMessageHeaders.java`
- 自定义 `DateTimeFormatter`：ISO 时间 + 纳秒（0-9 位自适应）+ UTC 偏移

### 31. RocketMQ 消费者（Push 模式）
- **源文件**：`ygh-notification-service/.../NotificationDomainEventConsumer.java`
- `DefaultMQPushConsumer`，订阅多 tag（TRAINING_ASSIGNED / WALLET_PAYMENT_SUCCEEDED / KNOWLEDGE_REVIEWED）
- `setMaxReconsumeTimes(8)`，`RECONSUME_LATER` 重试

### 32. 知识库 Outbox 配置
- **源文件**：`ygh-knowledge-service/.../KnowledgeOutboxConfiguration.java`
- `@ConditionalOnProperty(name="ygh.mq.enabled")` MQ 开关
- `@Bean(destroyMethod="close")` 优雅关闭生产者
- `@Scheduled(fixedDelayString)` 定时分发 outbox 表

## 四、数据库迁移安全

### 33. Flyway 配置守卫
- **源文件**：`ygh-common-mybatis/.../FlywayConfigurationGuard.java`
- 强制 `validateMigrationNaming` / `validateOnMigrate` / `cleanDisabled = true`
- 禁止 `outOfOrder` / `baselineOnMigrate` / `ignoreMigrationPatterns`
- 迁移路径必须匹配核准白名单

### 34. 仅向前迁移策略
- **源文件**：`ygh-common-mybatis/.../FlywayMigrationPolicy.java`
- 禁止 `R__`（可重复脚本）和 `U`（Undo 脚本）
- 版本号正则 `V<正整数>_<小写蛇形>.sql`
- 路径穿越检测 `../`
- 重复版本号 / 重复路径检测

### 35. Flyway 迁移执行拦截
- **源文件**：`ygh-common-mybatis/.../YghFlywayMigrationStrategy.java`
- 迁移前：配置校验 -> 静态规范验证 -> 版本号顺序检查
- 迁移后：`FlywayHistoryValidator` Checksum 再校验
- 禁止 Java 迁移，只允许 SQL

### 36. Mybatis-Plus 分页强制限制
- **源文件**：`ygh-common-mybatis/.../YghMybatisAutoConfiguration.java`
- `PaginationInnerInterceptor.setMaxLimit(DEFAULT_PAGE_SIZE)`
- `SmartInitializingSingleton` 启动时校验分页配置不可被覆盖
- 禁止分页溢出 `setOverflow(false)`

### 37. 审计字段自动填充
- **源文件**：`ygh-common-mybatis/.../AuditMetaObjectHandler.java`
- MyBatis-Plus `MetaObjectHandler` 自动填充
- 插入填充 createdBy / createdAt / updatedBy / updatedAt
- 更新只填充 updatedBy / updatedAt
- `AuditableEntity` 基类 `@TableField(updateStrategy = NEVER)` 保护创建字段不被修改

## 五、网关安全

### 38. JWT 验证器链
- **源文件**：`ygh-gateway/.../GatewayJwtValidators.java`
- Spring Security 默认验证器（exp / iss）+ 自定义 audience 验证器
- `DelegatingOAuth2TokenValidator` 组合，全部通过才放行

### 39. JWT 主体映射与安全校验
- **源文件**：`ygh-gateway/.../JwtPrincipalMapper.java`
- 从 Claims 提取 roles / permissions
- 最大 128 个权限，编码总长 ≤4096
- 正则 `[A-Za-z0-9][A-Za-z0-9-:.]{0,127}` 校验每个值

### 40. JWT 桥接过滤器
- **源文件**：`ygh-gateway/.../JwtPrincipalBridgeFilter.java`
- WebFlux 响应式：从 `ReactiveSecurityContextHolder` 获取 JWT
- 解析后存入 `exchange.getAttributes()` 供下游使用

### 41. Session 验证过滤器
- **源文件**：`ygh-gateway/.../JwtSessionValidationFilter.java`
- 从 JWT 提取 account_id + jti
- 三态：ACTIVE 放行 / REJECTED 401 / UNAVAILABLE 503
- `@ConditionalOnProperty` 可开关

### 42. 可信客户端 IP 签名
- **源文件**：`ygh-gateway/.../TrustedClientFilter.java`
- 网关边缘观测真实 IP -> HMAC 签名注入 Header
- 替换伪造的 `X-Forwarded-For`

### 43. 内部请求签名（服务间）
- **源文件**：`ygh-common-security/.../InternalRequestSignature.java`
- HMAC-SHA256，密钥 ≥32B
- 时间窗口校验 1s-5min，防重放
- canonical 拼接：clientIp / traceId / requestId / method / path / timestamp
- `MessageDigest.isEqual` 恒定时间比较

### 44. 内部用户上下文签名
- **源文件**：`ygh-common-security/.../InternalUserContextSignature.java`
- HMAC-SHA256
- canonical 拼接：userId / roles / permissions / traceId / requestId / method / path / timestamp
- 角色权限排序去重后拼接

### 45. 请求体大小守卫与 Chunked 传输检测
- **源文件**：`ygh-gateway/.../GatewayRequestGuardFilter.java` + `GatewayEdgeConfiguration.java`
- 普通请求 2MB，上传请求 50MB，上传路径白名单
- multipart 非 POST 或路径不在白名单 -> 403
- 上传请求缺失 Content-Length -> 411
- **Chunked 传输**（无 Content-Length）：`DataBufferUtils.join` 流式读取 + `DataBufferLimitException` 超限检测
- 装饰器模式保留 Body 供下游复用（`ServerHttpRequestDecorator`）

### 46. CORS 配置
- **源文件**：`ygh-gateway/.../GatewayCorsWebFilter.java` + `GatewayCorsConfiguration.java`

### 47. Sentinel 限流
- **源文件**：`ygh-gateway/.../GatewaySentinelRuleSet.java` + `GatewaySentinelConfiguration.java`

### 48. 关联 ID 全链路追踪
- **源文件**：`ygh-gateway/.../CorrelationIdFilter.java`
- 生成 / 传递 `X-Request-Id`

### 49. 网关安全错误响应写入器
- **源文件**：`ygh-gateway/.../GatewaySecurityErrorWriter.java`
- 6 种 HTTP 状态码：401（未认证）/ 403（无权限/上传路径拒绝）/ 411（缺 Content-Length）/ 413（请求体过大）/ 429（限流）/ 503（依赖不可用）
- 429 限流响应附加 `Retry-After` Header
- 响应已提交保护（`isCommitted()` 检查防重复写入）
- 使用 `tools.jackson.databind.ObjectMapper`（Jackson 3）序列化 `ApiResponse`

### 50. 网关异常处理
- **源文件**：`ygh-gateway/.../GatewayFailureWebExceptionHandler.java`
- 统一 JSON 错误响应，不暴露堆栈

### 51. 网关安全属性键常量
- **源文件**：`ygh-gateway/.../GatewaySecurityAttributes.java`
- TRACE_ID / REQUEST_ID / AUTHENTICATION_PRINCIPAL
- 使用类全限定名前缀确保键名唯一，避免与 Spring 内部属性冲突

### 52. 网关自定义 Header 常量
- **源文件**：`ygh-gateway/.../GatewayHeaders.java`
- 全套 `X-YGH-*` 头定义：User-Id / Roles / Permissions / Client-IP / Client-IP-Timestamp / Client-IP-Signature / User-Context-Timestamp / User-Context-Signature
- 下游微服务通过这些头获取网关注入的安全与追踪元数据

### 56. 当前用户主体

### 57. 资源访问守卫

## 十五、认证服务 Redis 落地与令牌签发

### 137. Redis 固定窗口双维度登录限流（RedisLoginRateLimiter）
- **证据**：`ygh-auth-service/.../infrastructure/RedisLoginRateLimiter.java`（提交 4c74517）
- Lua 脚本原子执行 `INCR` + 首增时 `PEXPIRE` + TTL 兜底，一次调用返回 `{allowed, ttl, count}`
- **双维度同时消耗**：principal（`SensitiveValueHasher.hashPrincipal`）+ IP（`hashClientAddress`），敏感值哈希后入 Redis
- 拒绝时返回限流维度（PRINCIPAL / IP / BOTH）与 `retryAfter`（双限流取较长 TTL）
- 构造时预热 `RedisKeyBuilder`，保证 key 规范格式

### 138. Redis 验证码原子消费（RedisCaptchaChallengeStore）
- **证据**：`ygh-auth-service/.../infrastructure/RedisCaptchaChallengeStore.java`（提交 4c74517）
- Lua 脚本 `GET -> DEL -> 比较` 原子完成"验证并删除"，一次性消费防重放暴力破解
- `setIfAbsent`（SET NX）保存，challengeId 冲突抛 `IllegalStateException`
- TTL 强制 1ms-10 分钟

### 139. JWT 实际签发与密钥对完整性校验落地
- **证据**：`NimbusAccessTokenIssuer.java` + `RsaSigningKeyRing.java`（提交 4c74517，修复 `return null`）

- 密钥环加载新增**三重配对校验**：modulus 匹配 + private exponent 匹配 + `verifyKeyPair` 32B 挑战签名验签
- 签名/加载失败统一包装 `IllegalStateException` 不泄露细节
